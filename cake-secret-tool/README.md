# 给你一块 · 手作蛋糕工坊

打开就是一块干净的蛋糕胚。五步完成制作：选胚 → 奶油 → 装饰 → 藏句话 → 预览与导出。

## 制作与分享

- 圆形、爱心、花朵、云朵、方形，三种蛋糕口味。
- 六种奶油颜色，一键铺面、自由挤奶油、奶油花、沿边裱花。
- 手绘水果与配料：草莓、蓝莓、樱桃、小花、蝴蝶结、蜡烛；点按放置、拖动移动、点按移除。
- 编辑支持撤销、恢复；返回上一步不清空作品；浏览器自动保存草稿。
- 蛋糕表面没有提示、标语或文字。可填写收件人、落款和最多 120 字的隐藏留言。
- 统一画布绘制完整蛋糕、刀切动画、两半分开和留言揭晓。
- 导出 720 × 1280 竖屏视频，约 10–21 秒，长留言自动延长停留时间。
- 优先生成 MP4；浏览器仅支持 WebM 时，会明确显示实际格式。没有伪装扩展名或将文案复制称为视频分享。
- 生成后可播放检查、下载、通过支持文件分享的系统面板发送；也可保存完整蛋糕 PNG。

## 运行

纯 HTML、CSS、JavaScript，无安装依赖、无第三方资源、无后端。通过静态网站访问 `index.html`，例如已有 GitHub Pages 的 `/cake-secret-tool/` 路径。本地开发可用 `python -m http.server 4173`。

视频使用 Canvas captureStream + MediaRecorder，不需要摄像头或麦克风权限。需浏览器支持录制；实际 MP4 编码和系统文件分享能力取决于浏览器。生成时请保持页面在前台，切换后台会取消生成，可以重新导出。

手机文件管理器的 HTML 预览、小红书/微信内置浏览器可能限制脚本、录制或下载，请使用系统浏览器打开网页。本项目是可独立运行的网页工具，尚未封装为小红书原生小工具。

## 文件

- `index.html`：制作工作台、视频预览与导出对话框。
- `styles.css`：桌面与手机响应式布局。
- `app.js`：蛋糕绘制、编辑历史、草稿、切开动画、视频生成与文件分享。

作品与留言只保存在当前浏览器，点击重做会清空；不会上传到服务器。视频中会显示用户填写的收件人、留言和落款。
