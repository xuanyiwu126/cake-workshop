# 给你一块｜隐藏信息蛋糕 MVP

一个面向手机竖屏的互动蛋糕创作原型。

## 当前能力
- 5 种蛋糕胚：圆形、爱心、云朵、星星、方块
- 手指/鼠标拖动挤奶油
- 多种奶油颜色
- 点击摆放水果与“怪配料”
- 生日、夸夸、好运、发疯、给自己、没理由 6 种创作情境
- 自定义蛋糕表面话术
- 自定义隐藏信息
- “切开蛋糕”动画后揭晓隐藏信息
- 随机灵感、发疯一下、撤销、清空装饰
- 浏览器原生分享能力（支持时）

## 使用
打开 `index.html`。手机端建议通过网页地址访问；部分手机系统的“文件预览器”不会完整执行 HTML/JavaScript。

## 产品定位
不是烘焙模拟器，而是“把情绪、关系和想说的话做成蛋糕”的分享型创作工具。
